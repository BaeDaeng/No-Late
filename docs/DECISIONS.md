# 기술 결정

- React/Vite와 가벼운 컴포넌트 상태를 유지한다. 별도 전역 상태 라이브러리는 도입하지 않는다.
- 지도·대중교통 경로는 Kakao API를 사용하고, ODsay는 경로 엔진에서 제거했다.
- Supabase가 데이터, 익명 인증, Edge Function을 담당한다. Firebase는 현재 앱 구성에 사용하지 않는다.
- 브라우저에는 Supabase URL/publishable key와 Kakao JavaScript key만 둔다. REST·공공 API 비밀키는 Supabase secrets에서만 사용한다.
- Edge Function은 JWT 검증을 유지한다. 첫 요청 시 익명 세션을 만들며, 저장 데이터는 RLS로 해당 세션 소유자만 읽는다.
- 공유 데이터는 좌표·주소·사용자 신체 입력을 제외하고 출발/도착 표시명, 경로 요약, 계산 결과만 24시간 보관한다.
- 실시간 도착 정보가 노선·방향과 확실히 일치하지 않거나 운행 정보가 없으면 실제 시각을 추정해 꾸며 내지 않고 보수적으로 계산한다.
- 출발 위험도는 통계적 지각 확률이 아니라 경로·날씨·실시간 대기·환승·신호 불확실성을 더한 설명용 점수다.
